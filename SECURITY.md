# Security

Please do not publish vulnerability details in an issue. Use a GitHub Security
Advisory for the `Shaurya2k06/LEASH` repository and include the affected
commit, reproduction steps, and impact.

Do not include wallet files, TEE authorization tokens, private account data, or
unredacted live artifacts in a report. The current supported release is the
latest commit on `main`; devnet evidence is not production assurance.
